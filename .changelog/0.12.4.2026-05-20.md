# 0.12.4 - 2026-05-20: Fix limelight animation on nav click

## Fixed
- Limelight animation now triggers correctly when clicking nav links (broken after commit b7c2ae5)
- Animation uses AbortController to properly clean up listeners on each `astro:page-load`, preventing memory leaks
- `data-is-navigating` guard preserved to prevent double-click navigation triggers

## Changed
- Replaced broken delegated click handler with per-element listeners inside `initNav()`
- Exposed `window.gsap` for E2E tests using `__E2E_TEST__` guard (matching `index.astro` pattern)

## Removed
- Obsolete `handleNavDelegatedClick` function and its registration
- Tests checking `hasNavClickDelegated` guard (no longer relevant)

## Added
- New E2E test `limelight animation triggers with correct parameters` that verifies:
  - GSAP animation is called with correct duration (0.4s) and easing (power2.inOut)
  - `onComplete` callback exists to trigger navigation after animation
  - Intermediate position check proves animation actually moves the limelight
