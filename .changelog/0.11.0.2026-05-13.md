# 0.11.0 - 2026-05-13: Testimonials carousel implementation

## Added
- Testimonials section now uses a carousel layout instead of stacked cards
- Navigation arrows for manual carousel control (prev/next)
- Auto-play functionality that rotates testimonials every 10 seconds
- Pause on hover and focus for better user control
- Touch/swipe support for mobile devices
- Keyboard navigation with arrow keys

## Changed
- Testimonials now display one at a time with 10% peek of neighboring slides
- Updated animation config to target `.testimonials-carousel` class instead of `.testimonials-stack`
- Carousel layout uses 80% slide width with padding to show neighboring content
