# 0.8.0 - 2026-05-10: Word-based scroll animation system refactor

## Added
- Implemented a "Word-Based Scroll Unit" (WU) system for unified animation pacing across all sections.
- Introduced `PX_PER_WU` and `MS_PER_WU` constants to synchronize scroll-driven and time-based animations.
- New two-phase initialization for the Hero section (Section 0) to prevent animation conflicts.

## Changed
- Refactored `src/pages/index.astro` to use a sequential Phase 1 (Time-based intro) and Phase 2 (Scroll-driven timeline) architecture.
- Section 0 scroll budget is now correctly calculated as outro-only.
- Scroll is now programmatically blocked during the initial hero intro to ensure visual integrity.
- Optimized GSAP cleanup using `clearProps: 'all'` and `t.kill()` to ensure a pristine state for scroll-back events.

## Fixed
- Resolved a critical bug where Section 0 elements would disappear or stay hidden when scrolling backwards.
- Fixed a race condition between the page-load animation and the scroll-driven timeline.
- Eliminated "stale state" issues in GSAP where elements recorded hidden values as their from-state.
- Corrected the outro sequencing logic to prevent phantom scroll gaps between sections.
