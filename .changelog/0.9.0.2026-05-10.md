# 0.9.0 - 2026-05-10: Playwright E2E infrastructure setup

## Added
- Playwright E2E testing infrastructure supporting both dev and preview modes (`tests/e2e/playwright.config.ts`).
- Custom Playwright fixture that automatically applies anti-flake measures (GSAP fast-forwarding and smooth-scroll disabling).
- Deterministic scrolling helper to ensure GSAP ScrollTrigger processes positions before assertions (`tests/e2e/helpers/scroll.ts`).
- Astro hydration helper that waits for the `astro:idle` event before starting tests.
- Smoke test for the landing page proving the end-to-end flow from server start to scroll validation.
- `test:e2e` npm script for easy local and CI execution.

## Changed
- `package.json` updated with `@playwright/test` dev dependency and E2E test scripts.
