# 0.3.0 - 2026-05-01: UI/UX and Accessibility improvements

## Added
- **Accessibility:** Skip-to-content link for keyboard and screen-reader users.
- **Navigation:** Mobile menu enhancements including a dedicated close button, backdrop overlay, and focus trapping.
- **Responsive Design:** New tablet-specific layout (769px–1024px) to bridge the gap between mobile and desktop.
- **Visuals:** Static poster image for the hero video to prevent blank states during loading (`public/hero-poster.webp`).
- **Animations:** Subtle staggered entrance animation for the hero section on page load.

## Changed
- **Performance:** Converted gallery images from PNG to WebP, resulting in an ~88% reduction in asset size.
- **Performance:** Optimized font loading by moving Google Fonts to `<link>` tags with preconnect hints.
- **Performance:** Reduced initial bandwidth usage by setting video `preload` to `metadata`.
- **Layout:** Adjusted gallery grid to 2 columns on desktop for improved readability within the split-screen column.
- **UX:** Softened navigation "Kontakt" CTA style to ensure visual hierarchy favors the hero primary action.
- **UX:** Increased button touch targets to 44px for better mobile usability.
- **Typography:** Increased footer font sizes for improved legibility on small screens.

## Fixed
- **Accessibility:** Restored visible focus rings for all interactive elements to aid keyboard navigation.
- **Accessibility:** Added `aria-hidden` to decorative icons and updated hamburger menu ARIA labels.
- **Performance:** Fixed GSAP `will-change` implementation to reduce unnecessary GPU memory usage.
- **Animations:** Restructured animation scripts to honor `prefers-reduced-motion` immediately on load.
- **Animations:** Fixed section "vanishing" issue where text would disappear when scrolling back up.
- **Layout:** Resolved layout drift on ultrawide screens by adding a max-width constraint to the hero container.
- **Layout:** Fixed "invisible gallery" bug by aligning asset extensions in code with actual filesystem formats.
