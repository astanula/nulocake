# 0.6.0 - 2026-05-02: Limelight navigation and smooth transitions

## Added
- New "Limelight" navigation effect in `Navigation.astro` featuring a sliding pink beam and spotlight glow.
- Enabled Astro `ClientRouter` in `Layout.astro` to provide seamless, SPA-like transitions between pages.
- Integrated programmatic navigation using `astro:transitions/client` to sync animations with page swaps.

## Changed
- Refactored the main navigation script to utilize GSAP for hardware-accelerated beam animations.
- Updated menu interaction to trigger the limelight movement on click instead of hover for a more intentional user experience.
- Fine-tuned limelight aesthetics, including a 50px wide bar, a 34-degree beam angle, and a soft "pool" shadow at the base.

## Fixed
- Eliminated the browser's native "blink" during page reloads by switching to client-side routing.
- Resolved a flash of unstyled content (FOUC) where the navigation beam would briefly flicker on initial page load.
